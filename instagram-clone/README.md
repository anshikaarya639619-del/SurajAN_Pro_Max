# InstaSphere — Instagram-style social app demo

A responsive, mobile-first photo-sharing frontend inspired by common social-media patterns.

## Included
- Feed, stories row, explore grid, profile, reels placeholder, and messages placeholder
- Like/unlike, save/unsave, comments, caption sharing, and create-post modal
- Local browser storage for demo posts/interactions
- Responsive bottom navigation on phones
- No credentials, passwords, or private data are collected

## Important limitations
This is a **frontend demo**, not a production Instagram clone. It does not have real user accounts, secure authentication, a database, image uploads, direct messaging, notifications, follow relationships, moderation, or Instagram API integration. User-created posts are stored only in the current browser/device. Use a backend (for example Supabase) for real multi-user features and configure security rules before public launch.
