## PAYMENT

The frontend is NOT a payment processor.

Before accepting real payments:

1. Connect an eligible payment provider.
2. Complete required verification.
3. Configure USD/international payments.
4. Verify payments server-side.
5. Create secure order records.
6. Deliver paid files through protected access.

---

## SECURITY

Never publish payment secrets
or private paid files in the public repository.
