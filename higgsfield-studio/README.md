# MotionLab — AI Video Studio Prototype

An independent, mobile-friendly AI video studio interface inspired by modern cinematic AI creation workflows. This project is not affiliated with or an exact copy of Higgsfield.

## Included
- Responsive desktop/mobile interface
- Prompt composer and character count
- Visual direction presets: Cinema, Dreamscape, Anime, Product Film
- Duration, aspect ratio, quality and camera-motion controls
- Local concept history via browser localStorage
- Copy prompt and download prompt brief
- No build step or dependencies

## Run
Open `index.html` in a browser, or publish the `higgsfield-studio` folder with any static hosting provider.

## Important limitation
This is a **front-end prototype**. It does not generate actual video files. To enable real text-to-video or image-to-video generation, connect a licensed video-generation provider through a secure backend/serverless function. Keep API keys on the server; never put secret keys in browser JavaScript.
